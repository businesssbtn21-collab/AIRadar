よくある質問

アプリは無料ですか？

ダウンロードは無料です。すべての機能をご利用いただくには、App内課金「フルアクセス」（買い切り・¥900）の購入が必要です。一度購入すれば、追加の費用はかかりません。

以前にアプリを購入しました。もう一度支払いが必要ですか？

いいえ。バージョン1.1以前に有料アプリとして購入された方は、追加のお支払いなしで引き続きすべての機能をご利用いただけます。もし課金画面が表示される場合は、画面下部の「購入を復元」をタップしてください。それでも解決しない場合は、上記メールアドレスまでご連絡ください。

機種変更しました。購入は引き継げますか？

はい。同じApple Accountでサインインした状態で、課金画面の「購入を復元」をタップしてください。

ウィジェットの追加方法は？

ホーム画面の何もないところを長押し → 左上の「＋」→「AIレーダー」を選択 → お好みのサイズを追加してください。ロック画面のウィジェットにも対応しています。

ウィジェットに表示するツールを絞り込めますか？

はい。ウィジェットを長押し →「ウィジェットを編集」から、カテゴリ（チャット・画像生成など）と期待度ランクで絞り込めます。

情報が更新されません

アプリを開いて一覧を下に引っ張ると再取得します。通信環境をご確認のうえ、それでも更新されない場合はご連絡ください。なお、バックグラウンドでの自動更新の実行タイミングはiOSが判断するため、すぐに反映されないことがあります。

通知が届きません

iPhoneの「設定」→「通知」→「AIレーダー」で通知が許可されているかご確認ください。アプリ内の設定画面で、通知するカテゴリ・種別・期待度のしきい値を変更できます。

プライバシーについて

AIレーダーは、アカウント登録を必要としません。個人を特定する情報の収集・送信・第三者への提供は行っていません。アプリの設定内容や取得した記事データは、お使いの端末内にのみ保存されます。
